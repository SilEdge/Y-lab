# Y Lab — интерактивный Y-маятник

Самостоятельный сайт на Vite и Three.js. Всё вычисляется в браузере. Серверная часть, база данных, API-ключи и регистрация не нужны. Шрифты и все зависимости интерфейса включены в сборку; CDN при работе сайта не используется.

## Быстрый запуск

Нужен Node.js 22.12 или новее.

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite, обычно http://localhost:5173.

Не открывайте index.html двойным щелчком: модульным скриптам нужен HTTP-сервер.

## Публикация на Vercel

### Через GitHub

1. Распакуйте архив и создайте GitHub-репозиторий из его содержимого. В корне должны лежать package.json, vercel.json, index.html и папка src.
2. В Vercel выберите Add New → Project и импортируйте этот репозиторий.
3. Framework Preset — Vite. Build Command — `npm run build`. Output Directory — `dist`. Эти настройки уже заданы в vercel.json.
4. Нажмите Deploy. Vercel выдаст HTTPS-ссылку. Переменные окружения не нужны.

### Сразу из папки проекта

```sh
npm install
npx vercel --prod
```

При первом запуске войдите в свой аккаунт Vercel и следуйте его вопросам. Команда создаст публичный сайт в вашем аккаунте и напечатает ссылку. Архив сам по себе не публикует сайт.

## Готовая сборка

В архив включена папка `dist`. Её можно разместить на любом статическом HTTP-хостинге без запуска Node.js на сервере. Для локальной проверки сборки:

```sh
npm run build
npm run preview
```

Сборка работает из корня домена. Для размещения в подпапке потребуется изменить Vite base и абсолютные пути публичных ресурсов.

## Что можно делать

- Вращать 3D-установку мышью или пальцем, приближать, выбирать вид спереди и сверху.
- Менять вертикальную глубину узла h, нижнюю длину ℓ и расстояние d между отверстиями.
- Задавать массу, начальные амплитуды, фазу, запуск без толчка и затухание.
- Переключаться между нелинейной физикой и аналитическими идеальными фигурами.
- Выбирать настройки 2:1, 3:2 и 3:1 при полной длине подвеса 40 см.
- Ставить на паузу, менять скорость, начинать заново и очищать след.
- Сохранять координаты в CSV и фигуру в SVG.

График траектории показывает последние 2400 отсчётов, примерно 20 секунд. В CSV сохраняется до 18000 последних отсчётов, примерно 150 секунд, либо данные с последней очистки следа. После изменения физических параметров эксперимент начинается заново. Пробел переключает паузу, если фокус не в поле ввода.

## Физическая модель

Все вычисления внутри physics.js выполняются в СИ. В интерфейсе длины показаны в сантиметрах, масса в граммах, фаза в градусах. g = 9,81 м/с².

Опорные точки: P = (−d/2,0,0), Q = (d/2,0,0). Ось z направлена вверх от уровня отверстий. Верхние ветви имеют одинаковую постоянную длину s = sqrt(h² + d²/4).

Предполагаются точечный шарик, невесомый узел, лёгкие нерастяжимые нити, отсутствие трения в узле и неподвижная опора. Пока все нити натянуты, равновесие невесомого узла требует, чтобы нижняя нить была перпендикулярна касательной к допустимой окружности движения узла.

Обобщённые координаты θ и α дают:

```text
ρ = h + ℓ cos θ
K = (0, h sin α, −h cos α)
C = (ℓ sin θ, ρ sin α, −ρ cos α)

T = m/2 · (ℓ² θ̇² + ρ² α̇²)
V = mg · (h + ℓ − ρ cos α)

θ̈ = −(ρ/ℓ) sin θ · α̇² − (g/ℓ) sin θ cos α − 2βθ̇
α̈ = (2ℓ/ρ) sin θ · θ̇α̇ − (g/ρ) sin α − 2βα̇
```

Эти уравнения выведены из уравнений Лагранжа. Сопротивление изотропное и линейное: F = −2mβv. Они интегрируются методом RK4 с постоянным шагом 1/480 с. Частота отрисовки не меняет шаг интегрирования. Когда вкладка скрыта, время модели не идёт; при сильных задержках кадров симуляция замедляется вместо увеличения численного шага.

Параметризация сохраняет длины нитей по построению. Натяжение нижней нити N и верхних нитей S₁, S₂ проверяется при каждом шаге:

```text
N = m · (g cos θ cos α + ℓ θ̇² + ρ cos θ α̇²)
S₁ + S₂ = N cos θ · s/h
S₁ − S₂ = N sin θ · s/(d/2)
```

Если натяжение становится неположительным, симуляция останавливается с предупреждением. Свободный полёт, ослабление нити и последующий удар натяжения здесь не моделируются. Предел начальной амплитуды по x выбирается с запасом до ослабления, но при некоторых сочетаниях параметров нелинейное движение всё же может достичь этой границы — тогда остановка корректна.

Высота уровня крепления для 3D-сцены равна max(50 см, h+ℓ+8 см). Она влияет только на положение установки, не на собственные частоты.

### Линейный режим

При малых углах эффективные длины Lx = ℓ, Ly = h+ℓ:

```text
ωx = sqrt(g/ℓ), ωy = sqrt(g/(h+ℓ))
Tx = 2π/ωx, Ty = 2π/ωy
r = fx/fy = sqrt((h+ℓ)/ℓ)
```

Используется аналитическое решение, включая слабое линейное затухание с сохранением заданных начальных координат и скоростей. 3D-подвес в этом режиме визуально подстраивается к аналитическим x и y; его движение не является решением нелинейных уравнений. Проверка натяжений относится к нелинейной модели и служит консервативным ограничением применимости визуализации.

В режиме «Через центр со скоростью» имя относится к δ=0: x(0)=Ax sin δ, vx(0)=Ax ωx cos δ, y(0)=0, vy(0)=Ay ωy. При ненулевой δ начальная координата x уже не равна нулю. «Отпустить без толчка» задаёт x(0)=Ax, y(0)=Ay и обе начальные скорости нулевыми. Амплитуды задают именно эти начальные условия; фактические максимумы нелинейного движения могут отличаться.

### Погрешности

Нулевую погрешность обещать нельзя. Показатель дрейфа энергии при β=0 — максимум |E(t)/E(0)−1| для численного нелинейного решения. Он не измеряет полную ошибку координат или отличие от реального опыта. При β>0 вместо дрейфа показывается остаточная энергия.

Периоды в интерфейсе — теоретические периоды малых колебаний. При конечных углах частоты нелинейного движения отличаются и могут дрейфовать. Идеальное рациональное отношение не обязано давать точно замкнутую нелинейную траекторию.

## Проверки

```sh
npm test
npm run build
```

Тесты проверяют базовые периоды из расчётной работы; сохранение трёх длин; сохранение энергии за 60 секунд; положительность натяжений; независимость движения от массы; переход к линейной теории; четвёртый порядок сходимости RK4; убывание энергии с затуханием; запуск без толчка; начальные скорости аналитического решения; обнаружение ослабления; пресеты и равновесие.

## Структура

```text
index.html           интерфейс и объяснение модели
src/physics.js       независимое вычислительное ядро
src/scene.js         3D-установка, камера и след
src/charts.js        Canvas-графики и SVG
src/main.js          управление экспериментом и CSV
src/style.css        адаптивное оформление
public/fonts/        локальные шрифты и лицензии OFL
tests/physics.test.js численные проверки
vercel.json          настройки публикации
dist/                готовая проверенная сборка
```

На странице нет аналитики или отправки параметров на сервер. Для 3D нужен браузер с WebGL и аппаратным ускорением. Если WebGL недоступен, остаются 2D-графики и расчёты.
